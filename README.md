# calc

A command-line calculator written in Python.

## Features
- Addition, subtraction, multiplication, division, power and remainder
- Handles division by zero and invalid input without crashing
- Clean output (5.0 is shown as 5)
- Runs in a loop until you type exit

## How to run
python calculator.py

## Example
addition / subtraction / multiplication / division / power / remainder / exit: addition
enter your first number: 6
enter your second number: 3
Result: 9
